# java-convenience-store-precourse
## 기능 구현 목록
### 입력 기능 구현 목록
- 구매 상품 및 수량 입력받기
- 프로모션 적용가능한 상품에 대해, 해당 수량보다 적게 가져온 경우 추가할지 여부 입력받기
- 프로모션 재고 부족할 경우, 일부 수량을 정가로 결제해도 되는지 입력받기
- 멤버십 적용 여부 입력받기
- 추가 구매 여부 입력받기

### 출력 기능 구현 목록
- 서비스 시작 문구 출력하기
- 보유 재고 현황 출력하기
  - 프로모션 상품만 있고, 일반 상품 재고가 없을 시에 `재고 없음` 출력하기
- 영수증 출력하기

### 서비스 기능 목록
- 재고 관리
  - products.md로부터 재고 불러오기
  - promotions.md로부터 프로모션 종류 불러오기
- 상품 구매 기능
  - 프로모션 상품에 대해, 해당 수보다 적게 가져오면 확인하기
  - 프로모션 상품 부족할 경우, 일반 상품에서 감소시키기
- 멤버십 적용
  - 30%할인, 대신 최대 8,000원까지 할인하기

### 예외 처리
- 사용자가 잘못된 값을 입력 시에, `[ERROR]`로 시작하는 문구 출력하기
